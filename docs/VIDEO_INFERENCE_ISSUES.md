# 비디오 추론 성능 저하 원인 분석

## 🔍 발견된 주요 문제점

### 1. **종횡비(Aspect Ratio) 왜곡 문제** ⚠️ 가장 심각

**현재 상황:**
- **학습 데이터 이미지**: 1280x1280 (정사각형)
- **비디오 프레임**: 720x1280 (세로가 긴 직사각형, 9:16 비율)
- **모델 입력 크기**: 192x192 (정사각형)

**문제:**
```
비디오 프레임 (720x1280) 
    ↓ 리사이즈
모델 입력 (192x192)
    ↓
종횡비 왜곡 발생!
```

**영향:**
- 객체가 찌그러져 보임
- 작은 객체가 더 작아짐
- 카메라 하단(도로) 영역이 압축됨
- 객체 위치 정보 왜곡

**해결 방안:**
1. **학습 시 종횡비 고려**: `rect=True` 옵션 사용 (letterbox padding)
2. **비디오와 유사한 종횡비로 학습**: 9:16 또는 16:9 비율 사용
3. **Multi-scale 학습**: 다양한 종횡비로 학습

---

### 2. **해상도 차이 문제**

**현재 상황:**
- **학습 이미지**: 1280x1280 → 192x192로 리사이즈 (6.67배 축소)
- **비디오 프레임**: 720x1280 → 192x192로 리사이즈 (평균 5.3배 축소)

**문제:**
- 비디오 프레임이 이미지보다 작은 해상도
- 작은 객체 탐지 어려움
- 디테일 손실

**영향:**
- 멀리 있는 차량/보행자 탐지 실패
- 작은 객체 (자전거, 신호등 등) 탐지 어려움

**해결 방안:**
- 이미지 크기 증가: 192 → 320 또는 416
- 비디오 해상도와 유사한 크기로 학습

---

### 3. **도메인 차이 (Domain Gap)**

**학습 데이터 (CARLA):**
- 시뮬레이션 환경
- 일정한 조명 조건
- 깨끗한 이미지
- 정확한 라벨링

**비디오 데이터 (BDD100K):**
- 실제 도로 환경
- 다양한 조명 (흐린 날, 그림자 등)
- 압축 아티팩트
- 모션 블러
- 카메라 흔들림

**영향:**
- 모델이 학습 데이터와 다른 환경에서 성능 저하
- 실제 환경 적응 어려움

---

### 4. **시간적 정보 부족**

**현재 모델:**
- 단일 프레임만 처리 (Temporal 정보 없음)
- 프레임 간 일관성 부족

**비디오 특성:**
- 연속된 프레임
- 객체 움직임
- 시간적 맥락 필요

**영향:**
- 프레임 간 탐지 불안정
- 움직이는 객체 추적 어려움
- 일시적 가려짐 처리 어려움

**해결 방안:**
- Temporal 모델 사용 (LSTM, GRU)
- Multi-frame 입력
- Tracking 알고리즘 추가

---

### 5. **모션 블러 및 압축 아티팩트**

**비디오 특성:**
- 빠른 움직임 → 모션 블러
- 비디오 압축 → 블록 아티팩트
- 낮은 비트레이트 → 디테일 손실

**영향:**
- 객체 경계가 흐려짐
- 탐지 정확도 저하
- False positive 증가

---

### 6. **카메라 각도 및 시점 차이**

**학습 데이터:**
- CARLA 시뮬레이션 카메라 각도
- 일정한 시점

**비디오:**
- 실제 차량 내부 카메라
- 다양한 각도
- 대시보드/스티어링휠 등 전경 객체

**영향:**
- 카메라 하단 편향 (대시보드에 집중)
- 전경 객체가 탐지를 방해
- 실제 도로 객체 탐지 어려움

## 🎯 우선순위별 해결 방안

### 🔴 1순위: 종횡비 문제 해결

**방법 1: Letterbox Padding 사용**
```python
train_kwargs = {
    "rect": True,  # 종횡비 유지하면서 padding
    "imgsz": 320,
}
```

**방법 2: 비디오와 유사한 종횡비로 학습**
```python
# 9:16 비율 유지
train_kwargs = {
    "imgsz": [288, 512],  # 9:16 비율
    "rect": False,
}
```

---

### 🟠 2순위: 이미지 크기 증가

```python
# 현재: 192x192
# 제안: 320x320 또는 416x416
train_kwargs = {
    "imgsz": 320,
}
```

---

### 🟡 3순위: 도메인 적응

1. **실제 비디오 데이터로 Fine-tuning**
   - BDD100K 비디오 프레임 추출
   - 라벨링 후 추가 학습

2. **데이터 증강 강화**
   - 다양한 조명 조건
   - 모션 블러 시뮬레이션
   - 압축 아티팩트 추가

---

### 🟢 4순위: Temporal 정보 활용

1. **Multi-frame 입력**
   - 3-5 프레임을 동시에 입력
   - Temporal 모델 사용

2. **Tracking 추가**
   - DeepSORT, ByteTrack 등
   - 프레임 간 일관성 향상
